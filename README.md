# html5-qrcode 精度検証ページ

GitHub Pages で公開して、スマートフォンのカメラから `html5-qrcode` の読み取り精度を確認するための最小構成です。

## 構成

- `index.html`
- CDN: `html5-qrcode@2.3.8`
- Code 128 / QR Code に対応
- カメラ選択
- 読み取り結果表示
- 期待値との一致・不一致判定
- 成功 / 不一致 / 失敗 / 総試行数の集計
- 検証履歴表示

## GitHub Pages 公開

1. GitHub に新しいリポジトリを作成
2. `index.html` と `.nojekyll` を push
3. GitHub の `Settings` → `Pages`
4. `Build and deployment` の `Source` を `Deploy from a branch`
5. `main` / `/ (root)` を選択
6. 保存
7. `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く

`github.io` の GitHub Pages サイトは HTTPS が自動的に利用できます。

## 精度検証方法

例えば同じ Code 128 を30回読み取ります。

- 期待値を入力
- 同じ距離・角度・照明条件でスキャン
- 読み取れたら成功として自動記録
- 読み取れなかったら「読み取れなかった（失敗）」を押す
- `成功 / 総試行 × 100` を読み取り成功率として比較

例:

成功 27回 / 総試行 30回 = 90%

## 注意

`html5-qrcode` 自体はカメラ映像からコードをデコードするライブラリです。
このページで測定できるのは、端末・カメラ・照明・距離・角度などを含めた実環境での読み取り結果です。

したがって、別ライブラリとの比較では、同じ端末・同じバーコード・同じ条件で測定してください。
